M1 — Vim Modal Editing
=======================
Status: IN PROGRESS
Next up: M1f (macros + dot repeat — skipped earlier per
user, last remaining M1 item) or move on to M2

Architecture: Enum state machine (VimMachine) in ms-view.
Each keypress → feed(key) → Option<Action>. No callbacks.
ms-term translates crossterm KeyEvent → KeyInput, feeds machine,
executes returned Actions.

M1a — Mode System + Basic Motions + Insert Mode + :w/:q   [DONE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
- Transaction system (ms-core): Retain/Delete/Insert ops, apply, invert
- Mode enum: Normal, Insert, Command
- Editor state: mode, command_buffer, status_message
- View: desired_col (w_curswant), h/l/0/$, column stickiness
- Document: apply_transaction(), save(), line_col_to_char()
- Application struct (Helix pattern): owns editor + terminal
- Async event loop: stream-based via crossterm EventStream, no polling
- Normal mode: h/j/k/l, 0/$, ^, w/W/b/B/e/E, gg/G, i/a/A/I/o/O, x, :
- Insert mode: typing, Enter, Backspace, Delete, arrows, Ctrl-w, Ctrl-u
- Command mode: :w, :q, :wq, :q!, :x
- Rendering: gutter, text, status bar, mode indicator, cursor shape

M1b — Operators + Vim Grammar State Machine               [DONE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
New: ms-view/src/command.rs — VimMachine, VimState, Action,
     Operator, Motion enums

Key types:
  Operator: Delete, Change, Yank, Indent, Dedent, Lowercase,
            Uppercase, ToggleCase
  Motion:   all from M1a + ParagraphForward/Back, FindChar,
            TillChar, MatchBracket, H/M/L
  MotionType: Charwise, Linewise, Blockwise
  MotionResult: { range, motion_type, inclusive }
  Action:   Move, OperatorMotion, EnterInsert, EnterCommand,
            Special, Undo, Redo, DotRepeat
  VimState: Normal, Count, OperatorPending, OperatorCount,
            WaitingChar, WaitingSecondKey

Grammar: [count] operator [count] motion
         operator operator (dd/yy/cc)
         special commands (x, X, s, S, r{char}, J, ~, o, O,
                           a, A, I, C, D, Y, >>, <<, p, P)

Editor additions: typeahead: VecDeque<KeyInput> (macro replay)

Verify: d2w deletes 2 words, 3dd deletes 3 lines, yy+p pastes

M1c — Text Objects + Visual Mode + Selections             [DONE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
New: ms-core/src/textobject.rs — word/paragraph/quote/pair
     (pure fns, Helix-ported algorithms, vim semantics)

Text objects: iw, aw, iW, aW, ip, ap,
              i"/a", i'/a', i`/a`, i(/a(, i[/a[, i{/a{, i</a<
Visual: v (charwise), V (linewise)
Mode::Visual { kind, anchor } — anchor lives in the mode,
maps onto ms-core Range for the future Selection refactor.

routes by mode. Selection rendered via ui.selection overlay
(Buffer::set_style merge). Visual p replaces selection.
Esc-from-insert only clamps (existing convention, no left
step); after linewise delete cursor goes to first non-blank
(vim dap preserves column instead — minor deviation).
Behavior verified against nvim -u NONE headless.

Deferred: Ctrl-V blockwise (VisualKind::Block defined,
unbound), is/as sentence objects, gv, visual r/J/:'<,'>

M1d — Undo/Redo Tree + Registers                          [DONE*]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
History (u/Ctrl-R) + full register grammar landed:
- "x select via Action::SelectRegister; applies to the
  next op only, count survives ("a3dd == 3"add). Works
  in visual mode ("+y from visual = user's keymap).
- Routing in ms-term commands.rs store_yank(): named
  "a-z (A-Z appends, paste joins), yank → "0, linewise
  deletes shift "1-9, small deletes → "-, "_ discards,
  "+ system clipboard (arboard, errors silent), unnamed
  always mirrors. x/s now fill registers too.
Behavior verified against nvim -u NONE headless.

Deferred: branch/tree undo (history is linear undo
stack), "% "." ": readonly registers, "* (primary),
clipboard feature gate (always on).

Verify: u undoes, Ctrl-R redoes, "ayy + "ap works ✓

M1e — Search + Marks                                       [DONE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
New: ms-core/src/search.rs — regex search over rope
     (regex crate directly, not grep-*; byte→char via
     rope.byte_to_char; wrapscan; \b word patterns)

Search: /pattern, ?pattern, n, N, *, # — all wired.
Incremental search (cursor preview + live ui.match
highlight while typing). Esc in prompt restores cursor;
Esc in normal mode = built-in nohlsearch (user's map).
Bare / repeats last pattern. Mode::Search { backward },
prompt reuses command_buffer + Prompt::search layer.
Marks: m{char}, '{mark} (linewise, first non-blank),
`{mark} (charwise exclusive), d'a/d`a, work in visual.
;/, repeat: Motion::RepeatFind substituted from
editor.last_find before resolution (d; works).
Behavior verified against nvim -u NONE headless.

Deferred: mark adjustment on edits, smartcase,
search history prompt (q/), search offsets (/pat/e),
visual-mode n/N.

Verify: /fn highlights, n cycles, * searches word ✓

M1g — Ex Command Line (full) + Polish                     [DONE]
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
New: ms-view/src/command_line.rs — pure ExCommand parser
(Address/ExRange/ExCommand), executor in ms-term.

Ex commands: :s/pat/rep/flags (g, i; any separator;
escaped sep), :%s, :1,5d, :e file (new-file + e!),
:w [path] (save-as), :N goto, :set number/nonumber/
number! (gutter toggles live), :theme. Ranges: number,
., $, %, 'mark, '<,'>. `:` from visual prefills '<,'>
(sets the marks). Substitute = single transaction
(one undo), cursor to last changed line, sets active
search pattern, reports "N substitutions on M lines".
Command history: Up/Down cycle (editor.command_history);
prompt component now delegates to commands::handle_command
so headless tests and TUI share one path.

NOTE: patterns are Rust regex syntax (same engine as /
search, Helix stance), NOT vim magic — \(\) groups are
(), but \1 backrefs in replacement are translated.
Behavior verified against nvim -u NONE headless.

Deferred: :g//, :normal, :y/:m/:t line ops, :set
beyond number, q: command-line window, search history
prompt.

Verify: :%s/foo/bar/g replaces all, :1,5d deletes ✓
